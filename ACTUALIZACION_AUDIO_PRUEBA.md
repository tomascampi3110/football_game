# Actualización de audio para la versión de prueba

- Se integraron los nueve temas proporcionados como archivos OGG para mejorar la compatibilidad con Kivy/Android.
- La reproducción musical es continua entre menús, carrera y partidos. La lista se mezcla y se evita repetir el mismo tema consecutivamente.
- Se agregaron efectos originales generados para esta versión: clic, entrada a la pantalla de carrera/lobby, golpe de pelota y celebración de gol. No se extrajeron efectos del juego HaxBall.
- Música y efectos se pueden activar/desactivar por separado.
- El botón `VOL.` permite ajustar ambos volúmenes de forma independiente.
- Las preferencias de audio se guardan para la próxima ejecución.

Los efectos son provisionales y se pueden reemplazar o ajustar según las pruebas de amigos.
